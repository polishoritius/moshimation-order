「我々は、応答のない世界にも呼びかける。」

## 目的

架空の秘密通信結社 MOSHIMATION ORDER の哲学・神話・戒律・預言・ユーモアを体系化した、増補可能な一冊の聖典を制作する。
本聖典はフィクションであり、実在の宗教・歴史ではない。信仰や服従を求めず、自由意志と対話を尊重する。
