# 全体構成案（Outline）

> **Status: DRAFT v0.1 — Owner未承認。** `[P-xx]` は新規提案、`[C-xx]` は確定設定（`canon-register.md` 参照）。

## 1. 聖典を貫く哲学

### 中心命題

> **呼びかけは義務ではなく贈り物であり、応答もまた贈り物である。** `[C-04][C-10]`

聖典は、人と人との関わりを「呼びかけ」と「応答」と「沈黙」の三つで捉える。

| 概念 | 意味 | 対応する教義 |
|---|---|---|
| 呼びかけ | 相手の返事を保証できないまま、声を差し出す勇気 | I |
| 沈黙 | 応答しない自由。拒絶・無関心・疲労・準備中など、理由は外から断定できない | II |
| 多声 | 自分と異なる声を奪わず、聞くこと | III |
| 疑い | 教義も始声者も検証されてよいこと。権威の相対化 | IV |
| 笑い | 重さに潰されないための知恵。他者を嘲る笑いは含まない | V |

### 三つの警戒（この聖典がしないこと）

1. **服従を求めない。** 教義は「守れ」ではなく「考えよ」の形で提示する。`[C-07]`
2. **沈黙を断罪しない。** 応答しない者を「冷たい」「信仰が足りない」と評価しない。`[C-06 II]`
3. **始声者を神格化しない。** 始声者は「最初に呼んだ者」であり、正しさの源ではない。`[P-06]`

### 世界観の基調

- 格式: 古典的で荘厳な文体。ただし読者を置き去りにしない平明さを保つ。
- 神秘性: 電波、受話器、回線、手回しハンドル、月桂樹を象徴として使う。`[C-08]`
- ユーモア: 大真面目な構えの中に、自然な笑いの余白を置く。`[C-06 V]`
- 独自性: 既存の宗教文献の語法（「〜は言った」「〜の子」型の系譜、預言者の召命譚など）を模倣しない。通信の語彙で独自に組み立てる。
- 位置づけ: 本書は結社内の「記録者」が編んだ寓話・思想書という体裁。実在の歴史ではない。`[C-09][Q-04]`

## 2. 番号体系 `[P-02]`

- **書（Book）**: 第一書〜第八書（漢数字）
- **章（Chapter）**: 書内で第一章から
- **節（Section）**: 章内で一節から。引用表記は `書:章:節`（例 `1:3:2` = 第一書 第三章 第二節）
- 各章の末尾に任意の「**余白節**」（`※`）を置く `[P-09]`
- 一節の長さは原則3〜6文。1節＝1思想。

## 3. 全8書の主題・役割・章立て

### 第一書 始声記（しせいき）— 世界の沈黙と最初の「もしもし」
**役割**: 世界観の起点。沈黙、最初の呼びかけ、認証語、始声者の相対化。
1. 第一章 静けさの前に — 沈黙の世界
2. 第二章 最初の呼びかけ — 第一声
3. 第三章 三重の波 — 呼ぶ・待つ・返す `[P-03]`
4. 第四章 ただ一つの言葉 — 認証語「もしもし」
5. 第五章 最初に呼んだ者 — 始声者の相対化 `[P-06]`
6. 第六章 回しすぎた手 — 最初の笑い `[P-08]`

（章の後に「結びの辞」`1:7` を置く）

### 第二書 五律記（ごりつき）— 五大教義とその解釈
**役割**: 五大教義の逐条解釈。各教義を「条文→問い→寓話→反例→余白」の形で扱う。
1. 第一章 呼びかけよ（I）
2. 第二章 沈黙を裁くな（II）
3. 第三章 声を奪うな（III）
4. 第四章 疑うことを恐れるな（IV）
5. 第五章 最後は笑え（V）
6. 第六章 五律の相互関係 — 教義同士が衝突するとき

### 第三書 聴守記（ちょうしゅき）— 応答の自由と沈黙の尊重
**役割**: 沈黙の多様な意味、聴く技術、「空線」の尊重 `[P-05]`。
1. 第一章 空線という名の敬意
2. 第二章 沈黙の七つの理由（疲れ・準備・恐れ・選択・不在・怒り・無言の応答）
3. 第三章 待つ作法 — 追い立てずに呼ぶ方法
4. 第四章 受話器を置く者 `[P-07]`
5. 第五章 聴守官（構想）の心得 `[S-01]`

### 第四書 伝声記（でんせいき）— 通信、交流、声の伝播
**役割**: 声が人から人へ渡る過程。誤伝・改変・拡散の倫理。
1. 第一章 声は伝わるうちに変わる
2. 第二章 中継者の責務 — 付け足さず、削り過ぎず
3. 第三章 秘密と公開 — 秘密通信結社の秘密とは何か
4. 第四章 拡散の節度 — 声の届け方と、押し付けの境
5. 第五章 伝声官（構想）の心得 `[S-01]`

### 第五書 結社記（けっしゃき）— 組織、役職、構成員の責務
**役割**: 組織の構想と責務。階級は優劣ではなく役割であることを強調 `[C-11]`。
1. 第一章 結社とは何か — 集まる理由と去る自由
2. 第二章 始声者・聴守官・伝声官・応声者（構想） `[S-01]`
3. 第三章 任命と解任 — 権力を分散する作法
4. 第四章 構成員の責務と権利
5. 第五章 内部批判の作法 — 疑いを制度にする `[C-06 IV]`

### 第六書 笑声記（しょうせいき）— ユーモアと神聖な迷言
**役割**: 笑いの哲学と「迷言」（誤り・言い間違いが生んだ名言）の収集。
1. 第一章 なぜ最後に笑うのか
2. 第二章 笑ってはならない笑い（嘲りの禁止）
3. 第三章 神聖なる迷言集（聴き間違い・掛け間違い・回し間違い）
4. 第四章 失敗の祝祭
5. 第五章 笑いが沈黙を救う夜

### 第七書 通信黙示録（つうしんもくしろく）— 失われた通信と世界の未来
**役割**: 失われた通信、未来予測の寓話。**断言的な預言はせず**、「ありうる未来」として複数提示し、読者の選択に委ねる。
1. 第一章 失われた回線
2. 第二章 三つの未来（誰も呼ばない世界／誰もが呼ぶ世界／呼びかけが響く世界）
3. 第三章 雑音の時代
4. 第四章 最後の受話器
5. 第五章 預言を疑う預言 — 預言の無効化条項

### 第八書 永続通信録（えいぞくつうしんろく）— 次世代へ引き継ぐ言葉
**役割**: 継承、増補、改訂。聖典自身を相対化して閉じる。
1. 第一章 継承の作法
2. 第二章 増補の規則 — 誰がどのように書き加えるか
3. 第三章 改訂の自由 — 聖典を疑う権利
4. 第四章 未来の呼び手への書簡
5. 第五章 結びの呼びかけ — 「もしもし」

## 4. 時系列・人物設定の整合方針

- **世界起源の寓話**（第一書）→ **教義の成立**（第二書）→ **応答と沈黙の実践**（第三書）→ **伝播と組織**（第四・五書）→ **笑い**（第六書）→ **未来**（第七書）→ **継承**（第八書）。
- 聖典内の年代は「第一声以前／以後」で表し、**西暦年代は創立日 2026-11-30 以外に用いない**。`[C-03]`
- 人物: 実在人物は登場させない。登場者は「始声者（最初に呼んだ者）」`[P-06]`、「記録者」（語り手）`[Q-04]`、象徴的人物（「雑音の旅人」「受話器を置いた老人」など無名の人物）に限る。
- 構成員名簿の人物（SUMIREら）は、Owner承認 `[Q-05]` まで聖典に登場させない。
